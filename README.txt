E-PORTOFOLIO SEMINAR PPG — Diky Andrianto

CARA MEMBUKA
1. Ekstrak ZIP ini ke satu folder.
2. Buka index.html menggunakan Chrome atau Edge.
3. Jangan pisahkan folder assets dan artefak dari index.html.

KARYA INOVASI
Produk utama adalah Digital Care E-Module. QR Keychain merupakan kemasan akses fisik yang menghubungkan pengguna ke media digital. Cyber Owl adalah aset identitas visual.

PRESENTASI
Tekan tombol Presentasi. Gunakan tombol panah kiri/kanan atau Space untuk maju/mundur. Tombol Esc keluar dari mode presentasi.


Perbaikan logo:
- Logo Digital Care pada pojok navigasi dan mode presentasi memakai latar transparan; bentuk shield tidak dipotong sudut kotak.
- Logo UKSW ditampilkan di dalam kotak persegi agar seluruh lingkaran dan tulisan logo terlihat utuh.
- File logo yang digunakan permanen ada di assets/digital-care-logo.png dan assets/uksw-logo.png.
- Ganti file tersebut dengan logo baru yang memiliki nama sama jika ingin memperbaruinya; jangan menghapus folder assets.

PRATINJAU WEBSITE

PRATINJAU KARYA INOVASI
Google Sites dapat menolak ditampilkan di dalam iframe eksternal. Karena itu, area pratinjau pada portofolio memuat artefak/Digital_Care_E_Module_Demo.html sebagai demo interaktif lokal. Gunakan tombol “Buka situs asli” untuk membuka website Google Sites yang dipublikasikan di tab baru. Demo lokal adalah representasi alur belajar, bukan salinan live website atau backend produksi.
